# Planer budżetu i ROI — ALK

## Uruchomienie na laptopie
1. Pobierz repo przez Code → Download ZIP.
2. Rozpakuj ZIP.
3. Otwórz plik planer-roi/index.html dwuklikiem w przeglądarce.

Nie wymaga serwera, Node.js ani internetu.

## Obsługa
Wpisz budżet roczny, zmień udział i oczekiwany ROI kategorii. Dodawaj własne kategorie. Dopilnuj, aby suma udziałów nie przekraczała 100%. Pobierz plan przyciskiem „Pobierz CSV”.

Wymagania i przykłady obliczeń: [PRD.md](PRD.md).

## Przykład kontrolny
100 000 zł, 50% przy ROI 20% i 50% przy ROI 40% daje 30 000 zł zysku, 130 000 zł kwoty końcowej i ROI 30%.

## Rozwój z Codexem
Przykładowe zadanie: „Przeczytaj planer-roi/PRD.md i dodaj zapis oraz odczyt planu w przeglądarce. Sprawdź obliczenia i przygotuj pull request”.

Kod w GitHubie nie aktualizuje automatycznie wcześniej opublikowanej aplikacji Sites. Publikacja strony jest osobnym krokiem.
